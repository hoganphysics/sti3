Installing Doxygen:
    sudo apt install doxygen

Installing Sphinx: 

    apt-get install python3-sphinx

Read the Docs Sphinx Theme: (for python3)

    pip3 install sphinx_rtd_theme
    pip3 install sphinx-tabs

Breathe: (for python3)

    pip3 install breathe
