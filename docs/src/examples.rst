.. _deviceexamples:

===============
Device Examples
===============

Usage examples of the STI device library can be found under `sti3/examples`.
Each example illustrates a different feature from the library. Examples are sorted
by target language.

* **simpleDevice**: The minimum working example of a device that connects to the STI network.
.. * testdevice: 

* **attributes**: Shows how to define attributes and define their setter and refresher callback functions.
* **configFile**: How to use configuration files (`*.ini`) to setup device parameters.
* **readWrite**: How to define input and ouput device channels and implement the `readChannel` and `writeChannel` functions for the device.
* **parseEvents**: Implementing the `parseEvents` device function for converting timing file events into hardware events.
* **fileMeasurement**: Shows how to write `collectMeasurementData` for an input channel that saves data to a file.
